## 这是什么

用「厚/黑」两轴诊断一个人靠不靠谱、为何成败,含失败复盘三段归因。卖的是**判断力和产出模板**,不是资料堆砌 —— 贴进 AI 就能直接干活。

## 它帮你做什么

- 两轴四型诊断(兼备/单轴/双缺/半吊子)
- 证据门槛(证据不足不硬打分)
- 失败复盘厚→黑→外部三段归因
- 四型固定输出模板

## 3 秒上手

1. 把本文件夹放进 `~/.claude/skills/`(全局)或项目 `.claude/skills/`
2. 重启 Claude Code
3. 说触发语,或直接描述你的场景

## 工作流程

收集两轴证据 → 打分诊断 → (复盘则三段归因) → 输出画像+行动提示

## 适合谁

要跟人打交道、谈合作、带团队、识人用人的职场人;做人才评估的管理者
