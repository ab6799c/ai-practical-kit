# 厚黑两维人性模型（h01，合并 h07 反身自省三段归因）

## R — 原文 (Reading)

> 據上面的研究，厚黑學這種學問，法子很簡單，用起來卻很神妙，小用小效，大用大效，劉邦司馬懿把它學完了，就統一天下；曹操劉備各得一偏，也能稱孤道寡，割據爭雄；韓信、范增，也是各得一偏，不幸生不逢時，偏偏與厚黑兼全的劉邦，並世而生，以致同歸失敗。
>
> — 李宗吾，《厚黑學》

> 有失敗之事於此，君子必自反也，我必不厚；其自反而厚矣，而失敗猶是也，君子必自反也，我必不黑；其自反而黑矣，其失敗猶是也，君子曰：反對我者，是亦妄人也已矣！
>
> — 李宗吾，《厚黑經》

## I — 方法论骨架 (Interpretation)

厚黑不是道德指控，而是两个独立的人格变量，任何人在任何场景都可测量：

「厚」= 抗压耐辱度：被羞辱、排挤、孤立、挫折时，能否不崩、不变形、不退场。
「黑」= 决断无情度：在利益冲突中，能否放下恻隐、不被恩义与不忍绑架、果断取舍。

两轴相互独立：可双高、可一高一低、可双低，谁也不能替谁。

评估人/组织/某次行为时，先悬置善恶判断，只看两轴量级与搭配：两轴兼备才成事（刘邦、司马懿）；单轴强则各有致命缺口（韩信厚而不黑、范增黑而不厚）；双缺最危险（项羽）。

同一模型反向用于自身：失败复盘按固定次序排查——先查厚维，再查黑维，两轴都排除后才允许归因外部（项羽「此天亡我」正是跳过前两步直接外归因）。

注意：这是观察透镜，不是授权自己行事的手册。

## A1 — 书中的应用 (Past Application)

### 案例 1：韩信——厚而不黑
- **问题**: 韩信手握重兵据齐地，是楚汉之外的第三方，有自立三分天下的窗口期。
- **方法论的使用**: 作者用两维分离评估——胯下之辱能忍，厚维不在刘邦之下；但对「黑」字欠研究，被刘邦解衣推食的恩义绑架，反复说「衣人之衣者，怀人之忧；食人之食者，死人之事」。
- **结论**: 单轴（厚）强大而黑维缺位 = 情感债务绑架决断，最佳窗口期错失自立。
- **结果**: 长乐钟室身首异处、夷及九族；且这正是他讥讽项羽「妇人之仁」的同一病根——知原则而未执行。

### 案例 2：范增——黑而不厚
- **问题**: 项羽首席谋士，欲置刘邦于死地，谋略与杀心皆足。
- **方法论的使用**: 黑维评估——心子之黑同刘邦仿佛；厚维评估——受不得气，中陈平离间计后大怒求去。
- **结论**: 黑维足而厚维缺 = 把尊严与情绪置于目标之上，一激即离场，正中对手下怀。
- **结果**: 归途至彭城疽发背死，项羽随之亡——「增不去，项羽不亡」。

### 案例 3：项羽——双缺（妇人之仁 + 匹夫之勇）
- **问题**: 武力最强的西楚霸王，却身死东城、为天下笑。
- **方法论的使用**: 两维同时诊断——鸿门宴项庄剑已出鞘却徘徊不忍放走刘邦（黑维缺）；垓下之败因「无面见江东父老」拒渡乌江（厚维缺），并把可改败局外归因「此天亡我，非战之罪」。
- **结论**: 双缺样本——不黑放走对手，不厚放弃翻盘，还跳过自省直接归因天命。
- **结果**: 身死东城；与刘邦对照构成「两轴兼备才成事」的完整证据。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估某人「行不行、靠不靠谱」，分析一个人或团队为何成功/失败。
2. 失败后的复盘会：想搞清楚「这事该怪谁」「为什么会黄」。
3. 谈判、竞争、合作之前，预判对手/合作方的软肋、底线与失效模式。
4. 困惑「能力很强的人为什么一直上不去」「老好人为什么总被欺负」。

### 语言信号 (用户的话里出现这些就应激活)

- 「他太软 / 太狠 / 太要面子 / 下不去手 / 妇人之仁 / 匹夫之勇」
- 「为什么他上不去 / 为什么总是失败 / 差在哪一截」
- 「复盘 / 归因 / 甩锅 / 这事该怪谁 / 别都怪环境」
- "too soft / too ruthless / thin-skinned / he can't bring himself / why is he stuck / attribution / retrospective / blame"

### 与相邻 skill 的区分 (定稿)

- 与 `houhei-lens-not-prescription`（h08）: h08 是使用本模型的元规则——h01 是「透镜」而非「处方」；先读 h08，防止把两轴模型当操作手册去刻意厚黑。本 skill 依赖 h08。
- 与 `houhei-veneer-detection`（h03）: h01 评估「厚/黑」两轴的量与搭配（性格配置），h03 评估「外衣与里子」的表里关系（包装是否暴露）；评估一个人时两者互补——h01 看配置，h03 看表里。
- 与 `houhei-pairwise-contrast`（h12）: 两轴模型是 h12「成败反察法」产出的一个结论；想验证或独立复现「厚黑两维」而非照单全收，用 h12 做配对对照。h01 是结论，h12 是生产结论的方法。
- 下游说明: `houhei-mastery-stages`（h02）、`houhei-responsibility-patterns`（h06）都建立在本模型之上（段位刻度、责任识别），触发它们时本 skill 是前置。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **定位对象 + 收集两轴行为证据**
   - 明确评估对象（人/组织/某次行为），先悬置道德判断。
   - 收集两类情境的证据：受辱受挫、被孤立排挤时的反应（厚维）；利益冲突、需要止损/争取时的取舍（黑维）。
   - 完成标准: 每轴至少 2-3 条来自不同情境的行为证据；证据不足时标注「证据不足」而不是硬打分。

2. **两轴打分 + 配置诊断**
   - 给「厚」「黑」各定强弱（或 0-10 分），归入四型: 两轴兼备 / 单轴缺位（韩信型厚强黑弱、范增型黑强厚弱）/ 双缺（项羽型）/ 半吊子（孙权型）。
   - 完成标准: 明确说出对象属哪种配置、缺在哪轴、最可能的失效模式。
   - 强制检查门(打分前): □每轴≥2条跨情境证据 □已排除单一情境误判 □评估对象已明确。任一未满足 → 停止打分,向用户输出待补证据清单,补齐后再继续。
   - 量化规则: 证据≥3条/轴 → 用 0-10 分量化;证据仅够定性 → 只用「强/中/弱」标签,不假装精确。
   - 判停条件: 若本次调用的目的是「为一次具体失败做复盘归因」，跳到步骤 3；若只是评估他人，直接跳到步骤 4。

3. **失败复盘三段归因（合并 h07）**
   - 按固定次序逐轴排除: ①先查厚维——失败是否因受不得气、放不下脸、提前退避？②够厚仍败，再查黑维——是否在该止损/该争取时犹豫、被恩义或不忍绑架？③两轴都排除后，才归因外部环境（时局、对手、运气）。
   - 判停点: 任一步查出明显短板即停下，不再向后归因；禁止跳过前两步直接说「天亡我」式外归因。
   - 完成标准: 归因链按「厚→黑→外部」顺序输出，并明确指出在哪一步查出问题，或三步全部排除。

4. **输出画像与行动提示**
   - 汇总对象的两轴画像 + 最可能失效模式（如「黑维缺位→关键决断会犹豫；厚维缺位→被羞辱/激将即退场」）。
   - 行动提示: 评估他人→据此预判其软肋并决定如何防/如何谈；评估自己→指出该补哪轴。
   - 完成标准: 产出一句可操作的结论（缺什么→会怎样→怎么办）。
   - 输出前自检闸门(缺一即重做): ①配置结论(四型) ②缺哪轴 ③失效模式 ④一句行动结论。
   - 四型固定输出模板（可直接套用）:
     - 两轴兼备: 「___兼具厚黑,成事概率高;风险在___。」
     - 单轴缺位: 「___厚/黑单轴强但缺___轴;关键场景会___,需补/需防。」
     - 双缺: 「___厚黑双缺,大事难托;最可能___。」
     - 半吊子: 「___两头不到底,行动不彻底比不行动更危险;建议___。」

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 想用它「教人厚黑」或「授权自己施展手段」——本书元警告「認真厚黑起來，是要終歸失敗的」，模型是透镜不是处方（h08）。
- 评估合作、创造、情感等非零和关系——作者样本全在权力争夺场景，未覆盖信任与合作的长期建构。
- 给对象贴道德标签（「他不厚道」「他太黑」）——模型是描述，不是判决。
- 只有单一情境证据就下结论——需多情境交叉验证。

### 作者在书中警告的失败模式

- 妇人之仁（ce01）: 心有不忍放走对手 = 黑维缺位，机会窗口不可逆。
- 匹夫之勇（ce02）: 受不得气放弃翻盘 + 外归因「天亡我」 = 厚维缺位。
- 韩信厚而不黑（ce03）: 恩义绑架错失自立，单轴。
- 范增黑而不厚（ce04）: 受不得气全盘输，单轴。
- 孙权黑厚俱半吊子（ce05）: 两头不到底，比缺一轴更糟——行动不彻底比不行动更危险。
- 被道学观念压伏天赋（ce15）: 道德教条旦旦而伐之，磨平判断与决断（失养日消）。

### 作者的盲点 / 时代局限

- 以成败论人性，幸存者偏差——失败者未必不厚黑，「成功」还受时势、运气与合作者影响。
- 样本集中于帝王/官场权力争夺，忽视合作、创造、情感情境；现代组织行为未被覆盖。
- 「厚黑天生固有」与「历史成败 = 厚黑程度」均未控制变量，属事后归因。
- 书中王导、明末武臣反例已触及厚黑策略的自我瓦解（失信失众），却被归为「补不起锅」而非模型缺陷。

### 容易混淆的邻近方法论

- 与「职场厚黑学/成功学」: 那些把厚黑当行动指南；本 skill 是观察评估工具。
- 与 h07 反身自省三段归因: 已合并入本 skill 步骤 3，勿再单列调用。
- 与性格标签/星座式人格: 本模型是两维可测量变量 + 可预测失效模式，不是模糊的性格描述。

### 技能自身运行故障路径（agent 执行时可能出错的地方）

- **单情境/单次事件证据**: 只给一次事件就要求诊断 → 明示缺哪类情境(受辱受挫 vs 利益冲突),拒绝下结论,列出可追问的问题清单。
- **一次评估多人**: 多个对象混在一起 → 逐人独立诊断,禁止合并成一张画像。
- **双轴矛盾证据**: 厚黑双高但行为证据互相矛盾 → 以行为为准,并输出置信度说明,不硬套四型。
- **非零和场景误触发**: 合作/创造/情感场景误激活 → 提示边界,立即终止评估。
