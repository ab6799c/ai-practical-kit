## 这是什么

把小说/剧本一键变成竖屏短剧视频。卖的是**判断力和产出模板**,不是资料堆砌 —— 贴进 AI 就能直接干活。

## 它帮你做什么

- 场景图自动生成
- 多角色配音
- 字幕压制
- Remotion 合成竖屏 MP4

## 3 秒上手

1. 把本文件夹放进 `~/.claude/skills/`(全局)或项目 `.claude/skills/`
2. 重启 Claude Code
3. 说触发语,或直接描述你的场景

## 工作流程

读取小说 → 提取场景/角色/对白 → 生成图像 → TTS 配音 → Remotion 合成 → 输出 MP4

## 适合谁

想做 AI 短剧/漫剧/口播视频,但不会剪辑、不会合成的创作者
