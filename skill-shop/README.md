# Skill Shop — AI 技能包商店

**把"行业老手的经验"打包成 AI 可直接调用的技能包。** 贴进 Claude Code / Coze 就能用,让 AI 立刻拥有某个领域的判断力。

## 在售技能包

### ① AI 短剧制作 · ¥49.9
小说 → 竖屏短剧一键成片(场景图/配音/字幕/Remotion 合成)
- **适合**: 想做短剧/漫剧/口播视频的内容创作者
- **上手**: 装好后说「把这部小说做成短剧」

### ② 代码之王写作 · ¥29.9
短句、高信息密度、表格+Emoji 锚点、冷叙事的写作风格包
- **适合**: 公众号/小红书/文案/短剧脚本创作者
- **上手**: 装好后说「用我的风格写」

### ③ 厚黑学·识人诊断 · ¥29.9
用「厚黑两轴」识人靠不靠谱、诊断成败、失败复盘归因
- **适合**: 要跟人打交道、谈合作、带团队、看人的职场人
- **上手**: 装好后说「帮我分析这个人靠不靠谱」

### ④ 孙子兵法·谈判应变 · ¥29.9
因敌制胜:打法随对手变,不硬套剧本,识别「机不可设」
- **适合**: 谈判、竞争、接单、商务博弈场景
- **上手**: 装好后说「上次的打法这次不灵了」

## 安装说明

每个技能包内都有完整 SKILL.md。以 Claude Code 为例:

1. 把技能文件夹放入 `~/.claude/skills/` 或项目 `.claude/skills/`
2. 重启会话
3. 直接说触发语即可自动生效
