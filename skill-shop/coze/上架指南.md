# Coze 技能商店 · 上架指南

你的技能包是标准 SKILL.md 格式,Coze 完全兼容,**无需改格式**。按下面步骤走:

## 1. 准备上传包
- 用 `deliverables/` 里的 zip(已剥离测试文件,纯技能包)
- 或把 `01-ai-short-drama/` 等文件夹直接 zip

## 2. 上传 + 部署(扣子官网)
1. 打开 coze.cn(国内)或 space.coze.cn,进入「扣子编程」→「技能」标签页
2. 点「上传 Skill 文件包」,选择 zip 上传
3. 平台自动解压分析,可先测试(输入案例看效果)
4. 点「部署」→「开始部署」,等几十秒完成

## 3. 上架到技能商店
1. 「技能商店 → 我的技能 → 我创建的」→ 找到技能
2. 点「更多」→「上架到商店」
3. 填:技能名称、一句话描述、详细描述、分类
4. 上传 3 个精选案例(对话测试截图)
5. 提交 → 显示「商店审核中」,等审核

## 4. 收费设置
- 选免费或按调用次数收费(付费支持支付宝/抖音支付)
- 收费需先开通扣子商户:code.coze.cn/merchant-management

## 5. 各 SKU 申请文案
见同目录的 `XX-上架.md`,复制粘贴即可。

## 注意
- 上架描述要含「做什么、何时用、输入输出是什么」,否则用户不敢买也难触发
- 扣子 Skill 云端运行,与 Claude Code(本地)使用场景不同,描述里说明清楚
- 生态建设早期,存在红利窗口,尽早占位
