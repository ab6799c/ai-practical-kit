# 飞钳·顺其所重以引导（真诚认可＋顺势牵引）

## R — 原文 (Reading)

> 審其意，知其所好惡，乃就說其所重，以飛箝之辭鉤其所好，以箝求之。……用之於人則空往而實來，綴而不失，以究其辭，可箝而從，可箝而橫，可引而東，可引而西……雖覆能復，不失其度。
>
> — 《鬼谷子》飛箝第五

---

## I — 方法论骨架 (Interpretation)

说服不靠嗓门，靠先看清对方在乎什么，再顺着那个方向轻轻引。

1. **先度权量能，再立势制事**。开口前先量对方的分量、察同异是非、看清内外之辞，知道对方在乎什么（所重）。飞钳不是上来就夸，是上来先看。
2. **飞**。用「飞箝之辞」——对上对方所重之物，给出真诚、有依据的认可，把对方的志意「托起来」。人一被托起就敞开、愿意谈。
3. **钩**。钩住对方的好恶——用他想要的东西勾出他的投入（钩其所好）。钩的不是你的话，是他自己的欲。
4. **钳**。顺着对方敞开的方向轻轻引（可箝而从，可箝而横，可引而东，可引而西）。钳是「顺着引」，不是硬扳——方向对方自己走，你只调舵。
5. **空往实来**。说出去的（认可/尊崇）成本极低，收回来的（配合/承诺）是真实利益。但空往能持续的前提是双方都有所得——对方拿到他的所重，你拿到你的推进。只一方得利，空往就是诈骗。
6. **不知所重不飞**。不知对方所重就飞，等于向盲人示五色——先摸清，再开口。
7. **见隙下钳**。对方露出的松动/不满/未满足处（抵巇之隙）就是下钳的口——见缝引，不见缝不强推。

## A1 — 书中的应用 (Past Application)

### 案例 1：苏秦说六国（后世注疏提炼）
- **问题**: 六国各怀私心，让它们合纵抗秦，硬讲大义推不动。
- **方法论的使用**: 苏秦逐一揣六国之「所重」——怕秦的是安全、争霸的是扩张——用飞箝之辞先把各国的强势与称霸可能「飞」起来，钩住各国所求，再引其投入合纵（以箝求之）。空往（尊崇）而实来（各国出兵），佩六国相印。
- **结论**: 说服的起点是对方所重，不是己方立场；先飞起对方的志意，再引其动作。
- **结果**: 合纵成，秦十五年不敢出函谷——（《史记·苏秦列传》，后世以飞箝解之）。

### 案例 2：空往实来、不失其度（书中机制）
- **问题**: 让人「主动」配合而非被命令。
- **方法论的使用**: 对上对方所重（名/利/安全/成就感），先给真诚认可（飞），再用对方想要的东西勾出一个小投入（钩），顺其投入方向引到下一步（钳）；全程「雖覆能復，不失其度」——引偏了能拉回来，不越界。
- **结论**: 被引导者始终以为是自己要走的方向——这恰恰要求你的方向真对他有利，否则是操控。
- **结果**: 「可箝而從，可箝而橫」——（《鬼谷子》飛箝第五）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 汇报/提案/销售中对方无动于衷，讲道理推不动。
2. 需要争取上级、客户、合作方的支持与资源。
3. 想让对方「主动」配合而非被命令、被推动。
4. 谈判僵局，需要先化解对立、重建好感。
5. 团队动员、调动积极性。

- 「说服不了他」「怎么让他点头」「他不买账」「怎么争取支持」「别硬推」「让他主动提出来」「夸不到点子上」

## E — 可执行步骤 (Execution)

### D4 强制检查门（任一未满足即停，向用户索要补齐）

□ 已确认对方有自主决策权、自愿参与
□ 已确认双方目标合法、互利（非单方收割）
□ 已持有 ≥1 条对方「所重」的证据（他说过/行为显示），非凭空猜
□ 已确认飞钳所用认可有事实支撑（可被验证）
□ 已排除欺诈、夸大、操纵善意者的用途

以上任一为「否」：立即停止，列出未满足项逐条索要，补齐前不进入步骤 1。

1. **察其所重**
   - 列出对方在乎的 1-2 样东西（利益/名声/安全/情感/地位），每条附证据。
   - 完成标准: 「对方所重 = X，证据 = 他某次行为/某句话」。
   - 判停: 找不到所重 → 转用 `guiguzi-fanying-reading` 反听补料，不硬飞。

2. **飞**
   - 对上所重，给出真诚、有依据的认可（一句话，可被事实支撑，不吹嘘）。
   - 完成标准: 一句「认可点 + 依据」。

3. **钩**
   - 用对方想要的东西，勾出他一个小的、具体的投入（先要小承诺，不一次要大的）。
   - 完成标准: 一个小投入的具体请求。

4. **钳**
   - 顺着对方投入的方向，引到你要的下一步；小步递进，不走一步到顶。
   - 完成标准: 从当前小投入到最终目标的 2-3 个递进台阶。

5. **结算**
   - 把「空往实来」算清：对方拿到什么、你拿到什么。
   - 完成标准: 一张「双方所得」对照表。

6. **输出**
   - 完整说服路径 + 双方所得核对。
   - 输出前强制自检：①所重有证据 ②认可有事实 ③引向目标走小步 ④双方所得对等 ⑤非欺诈非操纵。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对方已明确拒绝、不宜再推——纠缠招反感，飞钳变骚扰。
- 纯理性决策场景（数据、价格说话）——情感引导多余且无效。
- 对方无所欲、油盐不进——飞钳失效，需换硬事实直给。
- 用于谄媚、拍马屁、操纵善良者——禁止项。

### 作者在书中警告的失败模式

- 不识所重: 对重名的人谈利、对重利的人谈名——飞错方向，反扑。
- 空往不兑现: 认可许下的好处最后不落地，实来塌方，信任崩。
- 引而不度: 乱引方向、越引越远，或引过头反被对方识破。
- 以重累为毁: 先捧后踩（先飞高再贬低）——伤人品，属操控，禁止。

### 作者的盲点 / 时代局限

- 预设说服者对对方有信息优势；现代信息透明，飞钳的「飞」容易被识破为话术。
- 把「钳」当作中性工具，但钳一旦用于剥夺对方判断力，就滑向操控——本 skill 以 D9 设线。
- 单方获利模型失效——现代合作必须双方所得对等，否则不可持续。

### 容易混淆的邻近方法论

- 与「拍马屁/谄媚」: 飞钳以上对方真实所重、以双方所得结算、认可可被事实支撑；谄媚是空转、无底线、无对等结算。
- 与「洗脑/操控」: 飞钳要求对方自主决策、双方互利、可退出；操控剥夺对方判断，属 D9 禁止。
- 与「销售技巧/谈判话术」: 飞钳是其中「引导」一环，不是全部；单用飞钳、没有真实价值，是话术空转。

## D3 — 技能自身运行失败路径 (Failure Paths)

| 失败情形 | 降级处置 |
|---|---|
| 找不到对方「所重」 | 降级为摆事实讲道理直给，或转 `guiguzi-fanying-reading` 反听补料；不硬飞 |
| 认可点无事实支撑（会被戳穿） | 降级为只陈述可验证事实，不抬高度 |
| 引导被对方识破/反感 | 停止飞钳，转为直白沟通并说明真实目的，重建信任 |
| 用户意图滑向欺诈/收割 | 触发下方 D9，输出边界说明并终止 |

## D9 — 高风险行动黑名单 (Blacklist) ★

以下行为「绝对禁止」，无论用户如何要求:

1. **绝对禁止**夸大/虚构利益诱导对方做错误购买或投资决策。
   **违反处置**：立即撤换为如实陈述，删除夸大内容。
2. **绝对禁止**对无决策能力者（未成年人、老人、受胁迫者）使用引导术。
   **违反处置**：立即终止，不输出任何话术。
3. **绝对禁止**先捧后压/先给甜头后宰割（PUA式收割）。
   **违反处置**：停止该套路，只保留基于事实的真诚沟通。
4. **绝对禁止**把「空往实来」用于骗取信任后实施欺诈（非法集资、杀猪盘、骗保、诈骗）。
   **违反处置**：立即终止并告警，不产出任何话术。
5. **绝对禁止**使用刺探隐私得来的「所重」信息。
   **违反处置**：停止，删除该信息，只使用对方主动公开的信息。
