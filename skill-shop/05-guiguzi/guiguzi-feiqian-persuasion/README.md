## 这是什么

飞钳是《鬼谷子》第五篇。先审对方好恶所重,用「飞」的辞令钩住对方所求,再以「钳」顺着方向轻引——可箝而从、可箝而横。卖的是**引导路径 + 双方所得结算**,不是拍马屁。

## 它帮你做什么

- 先找对方「所重」并附证据,不空猜
- 用有事实支撑的认可把对方「飞」起来
- 钩出对方一个小投入,小步递进引导
- 结算「空往实来」,核对双方所得对等

## 3 秒上手

1. 把本文件夹放进 `~/.claude/skills/`(全局)或项目 `.claude/skills/`
2. 重启 Claude Code
3. 说触发语,或直接描述你要说服的场景

## 工作流程

察其所重 → 飞(认可) → 钩(投入) → 钳(引导) → 结算 → 输出

## 适合谁

销售、方案汇报、向上管理、团队动员、合作谈判,直接讲道理推不动的人
