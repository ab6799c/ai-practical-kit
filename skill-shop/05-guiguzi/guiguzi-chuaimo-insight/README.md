## 这是什么

揣摩取自《鬼谷子》揣篇第七、摩篇第八。情变于内者形见于外——从可见的外形推不可见的内情,如持钩临渊、投饵必得鱼。卖的是**识人判断力 + 识人报告模板**,不是猜心思。

## 它帮你做什么

- 先量权摆局势账,再谈揣情
- 选准关口(甚喜/甚惧),顺势推向所欲所恶
- 用十式摩法、以同类之事轻触探内符
- 输出需求/底线/软肋判断 + 证据链 + 置信度

## 3 秒上手

1. 把本文件夹放进 `~/.claude/skills/`(全局)或项目 `.claude/skills/`
2. 重启 Claude Code
3. 说触发语,或直接描述你要评估的场景

## 工作流程

量权 → 选关口 → 揣情 → 摩意 → 见形知隐 → 校验输出

## 适合谁

合作、谈判、用人、竞标、采购前,要看清对方真实需求与底线的人
