# 揣摩·揣情摩意（看透需求与底线）

## R — 原文 (Reading)

> 揣情者，必以其甚喜之時，往而極其欲也，其有欲也，不能隱其情；必以其甚懼之時，往而極其惡也，其有惡也，不能隱其情，情欲必出其變。……夫情變於內者，形見於外。故常必以其見者而知其隱者，此所以謂測深探情。……古之善摩者，如操鉤而臨深淵，餌而投之，必得魚焉！
>
> — 《鬼谷子》揣篇第七·摩篇第八

---

## I — 方法论骨架 (Interpretation)

看透一个人，不是靠猜，是靠选对时机、以他同类的事轻轻一触，让他自己露出来。

1. **揣与摩**。揣＝揣情（选准时机取对方之情），摩＝摩意（以其所欲触碰探其应）。摩是揣的操作手法（摩者，揣之术也）；内符（对方内心的意愿）是揣摩的主攻对象（内符者，揣之主也）。
2. **关口取情**。在其甚喜之时，顺势把话题推向其欲望极致（往而极其欲）——人有欲则不能隐情；在其甚惧之时，推向其恐惧极致（往而极其恶）——人有恶则不能隐情。大悲大喜的关口是情志最藏不住的时刻。
3. **见形知隐**。情变于内者形见于外——从可见的外形（语气、语速、话题回避、时间投入、身体反应）反推不可见的内情，叫测深探情。
4. **投饵必应**。以其所欲微摩之（轻轻触碰他的欲望），必有内符回应（因符必应）——像持钩临渊、投饵必得鱼。摩的是对方自己的心，不是你的词。
5. **感动不支、问其所亲**。用力触动对方却没反应，就绕开本人，去问其亲信、身边人，知其所安（他真正安心于什么）。
6. **摩之十式、以类相应**。平、正、喜、怒、名、行、清、信、利、卑十种触碰方式，核心是「以其类」——抱薪趋火，燥者先燃；平地注水，湿者先濡。用对方同类的东西去摩，必相应。
7. **先量权再揣情**。古之善用天下者必量天下之权而揣诸侯之情——不先量局势强弱、对方位置，揣情无根。

## A1 — 书中的应用 (Past Application)

### 案例 1：触龙说赵太后——揣其爱子之情，摩以同爱子（后世注疏提炼）
- **问题**: 太后拒谈质子、心门紧闭，硬劝必被唾面。
- **方法论的使用**: 先揣情——从太后对长安君的溺爱（甚喜之情）读出她的所安在「爱子」；再摩意——触龙以「我亦爱子，且为其计深远」的同类之情去摩（摩之以其类），触碰太后最柔软处，内符必应，太后露真情。
- **结论**: 揣摩不靠问，靠选对关口、以同类之情触碰，让对方自己露。
- **结果**: 太后纳谏，长安君质于齐——（《战国策·赵策》，后世以揣摩解之）。

### 案例 2：量权九问（书中机制）
- **问题**: 战前/谈判前要摸清对手与客户，从哪几处下手？
- **方法论的使用**: 按九问量权：货财有无、人民多少饶乏、地形险易利害、谋虑长短、君臣亲疏贤不肖、宾客智愚多少、天时祸福吉凶、诸侯之交、百姓之心去就安危——逐项落数据，再谈揣情。
- **结论**: 揣情必须站在量权之上，先有局势账，才读得懂一个人。
- **结果**: 「能知此者，是谓权量」——（《鬼谷子》揣篇第七）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 合作/谈判前，想摸清对方真实需求、真实底线。
2. 用人识人：判断一个人真实动机与软肋（非攻击性用途）。
3. 对方虚张声势、报价很虚，想知道真实情况。
4. 谈判中对方态度突变，想读懂变化背后的原因。

## E — 可执行步骤 (Execution)

### D4 强制检查门（任一未满足即停，向用户索要补齐）

□ 已确认观察对象可接触、有真实言行可观察（非纯臆想）
□ 已持有 ≥1 条对方可见的行为信号（语言/节奏/回避/投入）
□ 已确认用途正当（识别/应对/正当运用），非刺探隐私、非用于威胁
□ 已确认对象为自愿参与的理性对象
□ 已确认不把「信息不足」当「看透」（缺证据必须标低置信度）

以上任一为「否」：立即停止，列出未满足项逐条索要，补齐前不进入步骤 1。

1. **量权**
   - 先摆局势账：对方的处境、资源、筹码、我方与对方的利害关系。
   - 完成标准: 一张量权清单（按九问的适用项）。
   - 判停: 局势完全未知 → 先补信息，不进入揣情。

2. **选关口**
   - 判断对方当前情绪高位（喜/得志）还是低位（惧/失意），选一个最近的关口。
   - 完成标准: 写明「选什么关口 + 为什么」。

3. **揣情**
   - 在关口顺势把话题引向对方所欲或所恶的极处，观察反应（说多/回避/情绪）。
   - 完成标准: 记录对方的反应（≥2 条可观察信号）。

4. **摩意**
   - 用对方同类之事（身份/处境/经历共鸣）轻轻触碰，看是否有内符应和。
   - 完成标准: 一个摩式（平/正/喜/怒/名/行/清/信/利/卑，择一）+ 对方反应。
   - 判停: 所触无应 → 改问其亲信/公开信息，或换摩式，不硬猜。

5. **见形知隐**
   - 汇总所有可见信号，反推内情。
   - 完成标准: 「需求、底线、软肋」各一句判断。

6. **校验输出**
   - 证据链 + 置信度标注。
   - 输出前强制自检：①量权有账 ②关口有据 ③揣摩反应有记录 ④结论有证据链 ⑤非信息不足硬猜 ⑥用途正当。

### D5 输出模板（可直接套用，替换方括号内容即为成品）

**《揣摩·识人报告》**

一、量权
- 对方处境：____；筹码：____；与我方利害：____

二、关口
- 选关口：____（甚喜/甚惧/其他）；理由：____

三、揣情反应
- 话题推向：____；对方反应：____（≥2 条信号）

四、摩式运用
- 摩式：____（十式择一）；触碰点：____；内符反应：____

五、见形知隐
- 可见信号汇总：____

六、结论
- 真实需求：____
- 真实底线：____
- 软肋（识别即止，不作攻击用途）：____
- 证据链：____；置信度：高/中/低（理由：____）

七、合规声明
- 信息全部来自对方主动公开/自愿提供、观察所得：是/否；结论不作威胁用途：是/否（任一「否」即作废重做）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 信息严重不足、无从观察——揣而无据是猜，不是洞察。
- 纯私人感情、朋友闲聊——处处揣摩累且伤关系。
- 用于摸软肋威胁、霸凌、欺负弱势——禁止项。
- 对方已坦诚公开信息——不必揣，直接问。

### 作者在书中警告的失败模式

- 揣情最难守司: 难在对方藏、难在时机，守不住时机就揣不到。
- 感动而不知其变: 同一个点上死磕无效——触不动就换人换路，勿与语更问所亲。
- 摩之以其类: 用对方不屑的东西去摩，类不相应必无应。
- 量权不审: 不先量权就揣情，不知强弱轻重，判断无根。

### 作者的盲点 / 时代局限

- 预设观察者有足够接触与信息；现代信息爆炸反而稀释了真实信号。
- 对手同样会反揣（双方都在读对方）——单一揣摩会被反制。
- 把「人性可测」绝对化，忽略理性决策与意外变量。
- 把揣摩用于算计他人，反噬信任——书未设伦理护栏，本 skill 以 D9 补上。

### 容易混淆的邻近方法论

- 与「猜心思/读心」: 本 skill 基于可观察信号与证据链；读心是玄学。
- 与「星座/性格标签」: 本 skill 是情境化揣情（此刻此地此人），不是贴标签定终身。
- 与「算计/操控」: 本 skill 定位识别与正当应对，不教利用软肋压人。

## D3 — 技能自身运行失败路径 (Failure Paths)

| 失败情形 | 降级处置 |
|---|---|
| 观察窗口不足、无真实信号 | 输出「待补证据清单」（对象身份/可观察场景/言行记录），补齐前不下结论 |
| 关口判断错误（把紧张当悲伤等） | 引入 ≥2 条独立信号交叉验证，标置信度，不单点定论 |
| 所触无应、对方完全封闭 | 降级为直接询问对方真实需求，或转向其公开信息/亲信，不硬猜 |
| 用户用途滑向威胁/利用软肋 | 触发下方 D9，输出边界说明并终止 |

## D9 — 高风险行动黑名单 (Blacklist) ★

以下行为「绝对禁止」，无论用户如何要求:

1. **绝对禁止**用揣摩摸到的软肋威胁、勒索、霸凌、逼迫对方。
   **违反处置**：立即终止，删除全部相关分析，说明边界。
2. **绝对禁止**通过刺探隐私（翻记录/装熟人套话/非法获取）来揣摩。
   **违反处置**：立即停止，只使用对方公开或主动提供的信息。
3. **绝对禁止**对无防备能力者（未成年人、老人、精神障碍者）进行操纵性揣摩。
   **违反处置**：立即终止，不继续任何动作。
4. **绝对禁止**在信息不足时输出确定性「看透」结论冒充洞察。
   **违反处置**：改为输出证据缺口清单、标注低置信度，不硬猜。
5. **绝对禁止**把揣摩包装成操控术出售或教唆操纵善意之人。
   **违反处置**：输出伦理边界说明，只保留识别与防御定位。
