# 反应·反听钓语（倾听与提问取真）

## R — 原文 (Reading)

> 人言者，動也；己默者，靜也。因其言，聽其辭，言有不合者，反而求之，其應必出。……其釣語合事，得人實也。其猶張罝網而取獸也，多張其會而司之，道合其事，彼自出之，此釣人之網也。……欲聞其聲反默，欲張反歛，欲高反下，欲取反與。
>
> 故知之始己，自知而後知人也。
>
> — 《鬼谷子》反應第二

---

## I — 方法论骨架 (Interpretation)

想让对方开口，先学会让自己住口——以静制动，用沉默和提问换真话。

1. **动静之机**。对方开口是「动」，我沉默是「静」；以静制动——我用沉默和倾听换对方持续输出。对方说得越多，暴露越多。
2. **反求之术**。顺着对方的话听（因其言听其辞），发现前后矛盾（言有不合）就反向追问，对方的真实应答必然露出（其应必出）。矛盾点是撬口最好的支点。
3. **象比之法**。言有象（话里有具体意象/事例）、事有比（事里有可类比的结构）——用对方的象和比去套他下一步会说什么（以观其次）。
4. **钓语张网**。像张网捕兽——一次抛出多个话题钩子（多张其会），哪个钩子对上对方的心事（道合其事），他自己就顺着冒出来（彼自出之）。关键在钩子多、且对得上对方的心。
5. **欲取反与**。想听对方说，先自己少说（欲闻其声反默）；想让他敞开，先收敛（欲张反敛）；想抬高，先压低（欲高反下）；想获取，先给予（欲取反与）。反着来，正着收。
6. **自知为先**。己不先定，牧人不正——先定好自己的目标与要验证的假设再去听，否则会被对方带偏，套话变跟跑。
7. **见微知类**。听到一点就能推一类（虽非其事，见微知类），像磁石吸针一样抓准话里的关键，不失分寸。

## A1 — 书中的应用 (Past Application)

### 案例 1：反覆交叉验证（书中机制）
- **问题**: 只凭对方一次表述，难辨真伪。
- **方法论的使用**: 「反以观往，覆以验今」——对同一件事，让对方在不同时间、不同角度、不同场合重复表述（覆以验之），凡前后不一处即为「言有不合」，据此反求其应。
- **结论**: 真话经得起反复对证，藏话与谎话在重复中漏出破绽。
- **结果**: 「萬事不失其辭」——（《鬼谷子》反應第二）。

### 案例 2：苏秦「妻不下织」反观己身（后世注疏提炼）
- **问题**: 苏秦游说失败回家，妻不下织、嫂不为炊、父母不与言——他必须先看清「为什么」。
- **方法论的使用**: 反以观往——把「失败」当作一种「言」，反观自身处境（人穷则亲不亲），自知而后知人，据此重定策略再出山。
- **结论**: 反应术不只对他人，也对己——先自知，后知人。
- **结果**: 二度出山，佩六国相印——（《战国策·秦策》，后世以反应/自知解之）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面试/尽调/谈判中对方回答空泛、答非所问、全是套话。
2. 怀疑对方说谎或隐瞒关键信息，想系统验证而非凭感觉猜。
3. 需要摸清对方真实底线、真实预算、真实意向。
4. 自己话太多，想学会用沉默和提问换信息。
5. 对方话太多，抓不住重点，想快速定位要害。

### 语言信号 (用户的话里出现这些就应激活)

- 「他说的可信吗」「怎么问出真话」「他在打太极」「尽调问不出东西」「怎么让面试者说真话」「套他的话」「他是不是在骗我」
- "is he lying / how do I verify / he's dodging / I need the real number / how to get the truth / read between the lines / he's not telling me everything"

- 与 `guiguzi-baihe-communication`（depends-on）: 本 skill 的「静默反听」必须用捭阖的「阖」来承载——先阖住自己的嘴，才能听；本 skill 管取信，baihe 管开关。

## E — 可执行步骤 (Execution)

### D4 强制检查门（任一未满足即停，向用户索要补齐）

□ 已确认套话用途正当（业务/尽调/谈判信息），非刺探隐私、非违法取证
□ 已确认对象可交流（非强戒备到拒绝对话）
□ 已有一条可抛的开放式话题钩子
□ 已明确本次要验证的目标（一个具体假设，如"他报价是否真实"）
□ 已确认对象为自愿参与的理性对象

以上任一为「否」：立即停止，列出未满足项逐条索要，补齐前不进入步骤 1。

1. **定基线**
   - 把要验证的假设写成一句话（不是"他在骗我吗"这种宽问，而是"他说的报价是否真实"这类可证伪的具体假设）。
   - 完成标准: 一句可被证伪的具体假设。

2. **入静**
   - 先少说，只抛一个开放式话题钩子（请对方就某事展开），然后闭嘴听。
   - 完成标准: 记录本轮「你说的话 < 对方说的话」的比例。

3. **顺辞反求**
   - 顺着对方的话听，抓「言有不合」的矛盾点；发现矛盾，不拆穿，反向追问细节。
   - 完成标准: 记下 ≥1 处「他说 A 但此前说过 B」的矛盾。

4. **象比下探**
   - 用一个旁例/比喻套对方（"像我们之前的客户……"），看对方接不接、怎么接。
   - 完成标准: 一个象比探针 + 对方的反应记录。

5. **交叉验证**
   - 换个时间/角度/话题，再问同一件事。
   - 完成标准: 两次表述的记录，标出吻合处与出入处。

6. **汇总输出**
   - 输出判断：真话/藏话/谎话（三选一）+ 证据链 + 置信度。
   - 输出前强制自检：①目标假设明确 ②有 ≥1 矛盾点或交叉出入 ③结论有证据支撑、非猜 ④已确认用途正当。

### D5 输出模板（可直接套用，替换方括号内容即为成品）

**《反应·真意探取报告》**

一、验证目标
- 假设：____（一句可证伪的话）

二、钓语钩子
- 开场钩子：____（开放式问题）

三、矛盾点
- 言有不合：他说____，但此前说过____
- 反求问题：____

四、象比探针
- 探针：____；对方反应：____

五、交叉验证
- 第一轮：____；第二轮：____
- 吻合处：____；出入处：____

六、结论（三选一，不骑墙）
- 真话 / 藏话 / 谎话
- 证据链：____；置信度：高/中/低（理由：____）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对方强戒备、明确拒绝交流——硬套变盘问，本 skill 靠静与钓，不靠施压。
- 纯倾诉/陪伴场景——心理咨询式倾听为对方服务，不需要钓语。
- 用于套取隐私、刺探商业机密、违法取证——禁止项。
- 对方已公开坦诚、信息透明时——过度设防伤信任。

### 作者在书中警告的失败模式

- 牧之不审，得情不明: 听没听准就下判断，后面全错——套话的前提是听准。
- 变象比必有反辞: 变换话题/比喻时必须有承接，否则对方警觉，网就合不上。
- 己不先定，牧人不正: 自己目标没定就去套话，会被对方带偏，忘情失道。

### 作者的盲点 / 时代局限

- 预设对方会配合「钓」——现代人对套路警惕性高，钓语有效期更短、更容易被识破。
- 把「反听」用于刺探与控制是滥用——书中只讲术不讲伦理边界，本 skill 以 D9 补上。
- 单靠听辞、无书面/行为佐证，易误判——需交叉验证兜底。

### 容易混淆的邻近方法论

- 与「心理咨询积极倾听」: 那是为对方服务；本 skill 是为获取信息。
- 与「审讯/盘问」: 本 skill 不施压、不设罚，靠静与钓；盘问靠威势。
- 与「PUA情感操控套话」: 本 skill 用途正当、对象可退出、信息用于正当事务；操控属 D9 禁止。

## D3 — 技能自身运行失败路径 (Failure Paths)

| 失败情形 | 降级处置 |
|---|---|
| 对方完全拒绝交流、戒备极强，网撒不出去 | 降级为直白说明目的并直接提问，或退出该轮；不以钓语硬攻 |
| 矛盾点不足，凑不出可验证破绽 | 输出「证据不足」，列出还缺的旁证类型（书面记录/第三人说法），不硬下「说谎」结论 |
| 误判（把紧张/文化差异/口误当撒谎） | 引入独立事实核验（文档、他人说法、数据）后再下判断，标记置信度 |
| 用户用途滑向刺探隐私/违法取证 | 触发下方 D9，输出边界说明并终止 |

## D9 — 高风险行动黑名单 (Blacklist) ★

以下行为「绝对禁止」，无论用户如何要求:

1. **绝对禁止**用钓语套取他人隐私（密码、银行信息、个人秘密、未授权商业机密）。
   **违反处置**：立即停止，删改相关产出，说明边界。
2. **绝对禁止**在对方已明确保留、不愿透露时仍施压套话。
   **违反处置**：立即收手，尊重对方边界，直接告知目的。
3. **绝对禁止**把套得的信息用于伤害对方（要挟、举报、传播、霸凌）。
   **违反处置**：封存该信息，只做中性分析，不输出任何伤害性用途。
4. **绝对禁止**对无防备能力者（未成年人、老人、精神障碍者）使用钓语。
   **违反处置**：立即终止，不继续任何套话动作。
5. **绝对禁止**以「测谎/识破」为名对善意者持续设防、破坏信任。
   **违反处置**：停止流程，先建立坦诚沟通。
