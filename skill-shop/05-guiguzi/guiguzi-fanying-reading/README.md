## 这是什么

反应是《鬼谷子》第二篇。人言者动也、己默者静也——以静制动,顺着对方的话听,抓「言有不合」反求其应,用「钓语」张网让对方真意自己冒出来。卖的是**取真能力 + 探取报告模板**,不是话术堆砌。

## 它帮你做什么

- 定一条可证伪的验证假设,不空怀疑
- 用沉默与开放式钩子换对方输出
- 抓前后矛盾点、用象比探针下探
- 交叉验证后输出「真话/藏话/谎话」三态结论 + 置信度

## 3 秒上手

1. 把本文件夹放进 `~/.claude/skills/`(全局)或项目 `.claude/skills/`
2. 重启 Claude Code
3. 说触发语,或直接描述你要摸清的场景

## 工作流程

定基线 → 入静 → 顺辞反求 → 象比下探 → 交叉验证 → 汇总输出

## 适合谁

面试官、尽调、谈判、销售、采购,要判断对方说的是不是真话的人
