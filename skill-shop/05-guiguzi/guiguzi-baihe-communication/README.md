## 这是什么

捭阖是《鬼谷子》第一篇。捭者开也言也阳也,阖者闭也默也阴也——口是心之门户,谁控制开关,谁控制谈话节奏。卖的是**开关判断力 + 节奏方案模板**,不是资料堆砌。

## 它帮你做什么

- 判定对方当下是「开」(愿谈)还是「阖」(关闭)
- 定己方初始姿态:对方阖你先阖、对方开你随开
- 按阴阳定词靠拢对方心境,不硬碰
- 输出带转向信号的谈话节奏方案

## 3 秒上手

1. 把本文件夹放进 `~/.claude/skills/`(全局)或项目 `.claude/skills/`
2. 重启 Claude Code
3. 说触发语,或直接描述你的沟通场景

## 工作流程

判定开阖 → 定己方姿态 → 阴阳定词 → 定开关动作 → 设转向信号并输出

## 适合谁

谈判、汇报、销售、面试、会议、向上管理,常觉得「话说不说、什么时候说」失控的人
