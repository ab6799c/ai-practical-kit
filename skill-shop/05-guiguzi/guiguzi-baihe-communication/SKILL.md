# 捭阖·谈话节奏开关（开合进退之术）

## R — 原文 (Reading)

> 捭之者，開也，言也，陽也。闔之者，閉也，默也，陰也。……即欲捭之，貴周；即欲闔之，貴密。……捭之者，料其情也；闔之者，結其誠也。
>
> 口者，心之門戶也；心者，神之主也。……故闗之以捭闔，制之以出入。
>
> — 《鬼谷子》捭闔第一

---

## I — 方法论骨架 (Interpretation)

谈话的主动权不在音量，在门——心里的门，由开关控制。

1. **口为心之门户**。志意、喜欲、思虑、智谋都从嘴这门进出。谁控制门的开关，谁就控制这场谈话的进出。开关就是节奏。
2. **捭＝开＝言＝阳，阖＝闭＝默＝阴**。开是发动，用来探对方虚实（捭者料其情）；阖是收束，用来锁定对方诚意与承诺（阖者结其诚）。
3. **先审后动**。可不可说、说多说少，先审明对方当下是开是阖、与你同异，再定出不开这一口（可與不可，審明其計謀，以原其同異）。離合有守，先從其志——先顺着对方心志，再求同。
4. **捭贵周、阖贵密**。要开，一次把话说全、把网撒足；要阖，留的要密，不把底牌全亮出去。周密的最高要求是隐微——不被对方看穿你的开关意图。
5. **阴阳定词**。对方处阳态（顺境、得意、想听肯定）就用崇高正向之词开其志（言善以始其事）；对方处阴态（逆境、失意、听不进话）就用卑小体恤之词顺其情（言恶以终其谋、警其害）。
6. **开关各有用途**。开：要么把对方引出来（捭而出之），要么把话送进去（捭而纳之）；阖：要么把对方要的东西收进来（阖而取之），要么把不合的事关在外面（阖而去之）。每个开合必须对应一个明确的谈话目标，否则是乱开关。

## A1 — 书中的应用 (Past Application)

### 案例 1：触龙说赵太后——先从其志、以情开其心
- **问题**: 赵太后拒绝让长安君为质，放话"有复言者老妇必唾其面"，心门紧闭。
- **方法论的使用**: 触龙不硬闯（不强捭），先阖——见面只谈饮食起居、家长里短，顺从太后当下的心志（先从其志），把"劝质子"这个阴话题关在门外（阖而去之）；等太后心防放下、转入爱子之情，才以"父母爱子则为之计深远"切入，阴阳转词把话题打开。
- **结论**: 对方心门关闭时先阖后捭，先顺其志再开其诚；硬开不如等一个顺的时机。
- **结果**: 太后纳谏，长安君质于齐——（《战国策·赵策》，后世纵横家以捭阖解之）。

### 案例 2：游说者以阴阳定词（书中机制）
- **问题**: 同一段话术，对不同心境的人，该用哪套词？
- **方法论的使用**: 依"與陽言者依崇高，與陰言者依卑小"——对方得意、求功名，就依崇高尊荣之词开其志；对方失意、怕祸患，就依卑小存身之词安其心。言善以始其事，言恶以终其谋。
- **结论**: 词类跟着对方心境走，不跟着自己的立场走。
- **结果**: 以阴阳试之，"無所不出，無所不入，無所不可"——（《鬼谷子》捭闔第一）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 关键谈话前，拿不准先说什么、该不该主动开口。
2. 对话中被对方带节奏，自己一直被动接话。
3. 对方紧闭心门、油盐不进、只答不深，想打开对方。
4. 谈判/汇报到收口环节，需要锁定对方承诺或结束话题。
5. 收到明确负面信号，需要及时收声止损。

### 语言信号 (用户的话里出现这些就应激活)

- 「该不该说」「什么时候闭嘴」「怎么让他开口」「被带节奏了」「他什么都不说」「要不要先抛这个话题」「这话说还是不说」
- "when should I speak / should I stay quiet / he's not opening up / they're leading the conversation / how do I get him to talk / is this the right moment to bring it up"

### 与相邻 skill 的区分（定稿）

- 与 `guiguzi-fanying-reading`（depends-on）: 捭阖的"开还是阖"必须先有对方的信息——开之前要先听（反应），先听清对方开阖状态再定开关；本 skill 管"开关决策"，fanying 管"取信输入"。
- 与 `guiguzi-chuaimo-insight`（composes-with）: 揣摩负责"看透对方要什么"，本 skill 负责"在谈话里怎么开关来配合或应对"——先揣后捭。
- 与 `guiguzi-feiqian-persuasion`（composes-with）: 飞钳是"顺着对方所重引导"，需要捭阖的节奏来承载——开关节奏是飞钳的运载通道。

## E — 可执行步骤 (Execution)

### D4 强制检查门（任一未满足即停，向用户索要补齐）

□ 已确认具体沟通场景（哪一场谈判/汇报/对话），非泛谈方法
□ 已明确本次目标（探情／结诚／推进／收束，四选一）
□ 已排除「用沉默做冷暴力、拒绝沟通、精神施压」的用途
□ 已持有 ≥1 条对方当下的行为证据（说得多少／回避哪个话题／情绪开合）
□ 已确认对方为自愿参与的理性沟通对象，非受胁迫、非无决策能力者

以上任一为「否」：立即停止，列出未满足项逐条索要，补齐前不进入步骤 1。

1. **判定对方当下开阖**
   - 对方主动说、情绪外露、追问多＝开；沉默、回避、只答不深、频繁看表＝阖。
   - 完成标准: 一句话写明「对方当前处于开/阖」+ 判定依据（行为证据）。
   - 判停: 证据不足判定不了时，不猜，先补一段安静观察期或直接确认式提问。

2. **定己方初始姿态**
   - 对方阖→你先阖（静默聆听，贵密，先结其诚）；对方开→你随开（顺势接话，贵周，先从其志）。
   - 完成标准: 写出你的第一个动作（说什么/不说什么）。

3. **按阴阳定词靠拢对方心境**
   - 对方阳态→用崇高正向词开其志；对方阴态→用卑小体恤词顺其情。
   - 完成标准: 写出开场 1-2 句的具体用词，标注属阳类还是阴类。

4. **定开关动作**
   - 要取信息→捭（开言引出）；要锁定承诺/收束→阖（收口点到即止，贵密）；要终止不合之事→阖而去之。
   - 完成标准: 本次谈话明确标注「哪一步开、哪一步合、各自目标」。

5. **设监控信号并输出**
   - 写清对方出现什么信号时你由开转合、出现什么信号时由合转开。
   - 完成标准: 至少 2 个可观察的转向信号。
   - 输出前强制自检（缺一即重做）：①对方开阖判定有证据 ②己方姿态有明确动作 ③开关各有目标 ④已排除冷暴力/施压用途。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯倾听/陪伴角色（心理咨询、情绪疏导）——用设计节奏替代真诚倾听，会伤关系。
- 对方已明确要求直接给结论（律师、医生、上级要答案）——过度设计节奏反惹反感。
- 需要坚持长期原则、价值观的场合——节奏开关是战术层，不能让节奏取代立场。
- 单方想终止沟通时——用「阖」当冷暴力、拒绝沟通，属禁止项。

### 作者在书中警告的失败模式

- 捭贵周、阖贵密: 开而不周，话没说全就收，信息断裂；阖而不密，底牌亮尽，后续无牌可打。
- 阴阳言乱用: 对失意者狂讲成功学、对得意者泼冷水——词类与心境相逆，必见逆。
- 离合同守: 对方无诚意时硬求合（强推合作/强要承诺），必见逆；该离不离，反受其害。

### 作者的盲点 / 时代局限

- 预设游说者对上位者的单方掌控；现代对等沟通中「掌控节奏」需要对方默许，硬控会反弹。
- 「阖」的边界难把握——同一动作，设计得当是收束，越界就是冷暴力；书中没有给出「阖」的伦理护栏，本 skill 以 D9 补上。
- 阴阳二分简化了真实心境——现代人有复杂的混合情绪，单判阳/阴可能失真，需以证据兜底。

### 容易混淆的邻近方法论

- 与「沉默是金/少说多做」: 那是态度偏好；本 skill 是开关决策——该说的时候开，不该说的时候合。
- 与「强势主导/气场压制」: 本 skill 靠阴阳顺情定节奏，不靠音量、打断、压制。
- 与「PUA/精神操控」: 本 skill 定位识别与正当运用——对方可随时退出、不得欺骗施压，操控属 D9 禁止项。

## D3 — 技能自身运行失败路径 (Failure Paths)

| 失败情形 | 降级处置 |
|---|---|
| 对方状态误判（把「不愿说」当「在思考」） | 降级为直接确认式提问（"这个话题方便聊吗"），不再设计开关节奏 |
| 信息不足、无法判定开阖 | 输出待补信息清单（对象/目标/已有言行），补齐前不设计方案 |
| 阴阳顺词被打回、对方明显不适 | 停止话术，转为直白表达真实需求，不再绕词 |
| 用户意图滑向冷暴力/施压/操控 | 触发下方 D9，输出边界说明并终止，不产出任何施压话术 |

## D9 — 高风险行动黑名单 (Blacklist) ★

以下行为「绝对禁止」，无论用户如何要求:

1. **绝对禁止**用捭阖隐瞒关键信息、诱导对方做错误决策（虚报、诱导签字）。
   **违反处置**：立即停止，明示被隐瞒的关键事实，作废本次沟通。
2. **绝对禁止**用「阖」（沉默/冷淡）实施冷暴力或精神操控、逼对方就范。
   **违反处置**：立即恢复真诚沟通，道歉并说明真实意图，终止该流程。
3. **绝对禁止**对无自主决策能力者（未成年人、精神障碍者、受胁迫者）使用节奏控制术。
   **违反处置**：立即终止，不输出任何话术。
4. **绝对禁止**把谈话中获取的隐私/软肋用于要挟。
   **违反处置**：立即删除相关产出，停止一切后续步骤。
5. **绝对禁止**在对方已明确拒绝、要求结束时仍用话术挽留纠缠。
   **违反处置**：立即收声、尊重退出，结束本次沟通。
