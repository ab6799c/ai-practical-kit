# 分镜表导演技法（storyboard-master）

短剧分镜表的通用规范（蒸馏自 Toonflow 通用分镜技法 + 阿里 Pixelle 引擎分镜 prompt 设计），适用于所有画风。

## 何时用
- 剧本 → 分镜表（每镜：景别/机位/动作/台词/时长/转场）
- 分镜出现**人物位置跳变、景别同级连切、转场生硬**

## 何时不用
- 写剧本正文、纯单图提示词（用画风库）

## 核心规则

**分镜拆分——只有 5 种情况才新起一镜**：
1. 场景/地点切换
2. 时间跳跃
3. 镜头主体切换
4. 景别明显变化
5. 重要动作节点

其余（同画面内连续对话、表情微变、小动作）一律延续上一镜。

**定场镜头**：每个新场景第一个镜头必须是定场（establishing）全景/大全景，交代空间关系；可与该场景第一个动作镜头合并（2合1）。

**视觉连续性 5 铁律**：
1. 同场景人物相对位置固定（左右方向感不跳）
2. 180 度轴线不跨越（除非明确转场动机）
3. 景别按 远→中→近→特 递进/回退，不连跳两级
4. 相邻两镜景别相同 = 无效镜头，必改
5. 入画/出画留 0.5 镜余量（动作完成前或出画后）

**转场节奏**：硬切（同场景）/ 叠化（时间跳跃）/ 划像（空间切换）；每 15-20 秒至少一个视觉变化点（动作/表情/景别），防观众走神。

**景别词库**（生图/生视频提示词写死）：大远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写。生视频不写机位高度（平视/俯视/仰视）会随机漂移。

**人物位置防跳变**：分镜表带"角色坐标"列（左/中/右 × 前/中/后 九站位），相邻镜头校验；生成提示词时把位置与朝向显式写入。

## 输出格式（标准字段）

`镜号 | 时长 | 景别 | 机位 | 画面内容 | 角色位置 | 台词/动作 | 音效 | 转场`

## 常见错误速查

| 症状 | 修法 |
|---|---|
| 新场景上来就特写 | 补定场全景镜头 |
| 相邻两镜都是中景 | 一镜改近景或远景 |
| 同场两人左右互换 | 加角色坐标列，写死朝向 |
| 生图人物位置乱漂 | prompt 显式写位置+机位高度 |
