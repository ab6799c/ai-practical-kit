# 2D 扁平风（Flat Design）· 画风锚定提示词

> 自包含画风模块：把本文件"风格基因"段抄进每条 image_prompt 开头，角色/场景一致性立刻提升。
> 适用：Q版搞笑短剧、轻动画、明快都市题材。

## 风格基因（提示词锚定段，直接复制）

```
2D扁平风 Flat Design：几何造型，纯色色块，简洁线条，无阴影无渐变；
明快清新，简约现代；色块对比表达层次，纯色填充。
画幅竖屏 9:16，高细节，统一色盘：明快蓝#3B82F6 / 活力橙#F59E0B / 纯净白#FFFFFF / 深棕发#4A3728 / 高级灰#8A8A8A / 淡紫#C084FC / 暖粉#FB7185 / 浅黄#FDE047 / 米白#FEF3C7 / 薄荷绿#5EEAD4。
```

## 角色生成规则（约束手册摘要）

1. **轮廓即灵魂**：线条是角色唯一锚点，扁平色块分层构建；角色四视图（正面/侧面/背面/3/4）轮廓、体型、发型、基础服装必须一致
2. **角色为本**：基础着装由角色描述（身份/职业/性别/场景）决定，特定服化是叠加层
3. **面容自由**：五官不固定参数，由"性别/年龄/性格/气质"驱动生成，保证多角色外观差异化
4. **色块表达**：无阴影渐变，靠色块对比分前后景

## 情绪色盘（分镜对齐用）

| 情绪 | 主色 | 辅色 | 关键词 |
|---|---|---|---|
| 日常温馨 | 米白 | 白+灰 | 生活感、温暖、平静 |
| 心动瞬间 | 暖粉 | 橙+米白 | 羞涩、靠近、暧昧 |
| 办公学习 | 蓝 | 白+灰 | 高效、冷静、专业 |
| 浪漫场景 | 暖粉 | 橙+浅黄 | 甜蜜、温暖 |
| 夜晚场景 | 淡紫 | 蓝+橙 | 静谧、神秘、思考 |
