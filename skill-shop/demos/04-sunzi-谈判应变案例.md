# Demo ④ · 孙子兵法·谈判应变

## 用户输入
> 我是做企业服务的,以前谈单都是"先送试用 → 让对方尝到甜头 → 再报价",成功率挺高。但这半年对手把我们这套学走了,客户试用完两家比价,老用低价压我们。上次那套打法不灵了,怎么变?

## 技能输出(因敌制胜)

**① 识别本次变化点(≥3 条证据)**

| 变化点 | 对手做了什么 |
|--------|-------------|
| 1 | 对手复制了"试用→甜头→报价"打法,客户试用完两家比价 |
| 2 | 客户决策从"体验驱动"变成"价格驱动"(被低价教育了) |
| 3 | 时点变了:市场供给变多,试用成惯例,不再是差异化 |

**② 针对变化点设计变招**

| 变化点 | 变招 | 类型 |
|--------|------|------|
| 1 对手学走 | 不再把"试用"当钩子,改成"陪跑方案"绑定结果(试用即开始定制) | 反应式 |
| 2 价格驱动 | 报价策略从"报总价"改为"报结构"(服务分层,低价入口+增值阶梯) | 主动设伏 |
| 3 试用成惯例 | 把差异化从"试用"移到"数据":试用期就交付专属诊断报告,带不走的才是壁垒 | 反应式 |

**③ 检查预设剧本陷阱**
- 旧剧本"先试用再报价"是硬性顺序 → 已删除,改为"按对手反应分支"方案 ✓
- 新增分支:若对手跟进"陪跑方案" → 用"结果对赌"升级(达不到效果退款) → 拼落地不拼话术

## 输出结论(本次打法)
> 本次采用「**从卖试用改为卖陪跑 + 结果对赌**」:试用期交付专属诊断报告(带不走),报价改结构,对手若跟进就用结果对赌拉开身位。
> 下次变阵信号:① 若对手也开始"结果对赌" → 转拼交付速度 ② 若客户流失率上升 → 说明变阵过头,回调体验权重。
