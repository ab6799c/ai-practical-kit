# Demo ① · AI 短剧制作(实测跑通)

## 用户输入
> 把《第1集 · 老板的秘密》做成短剧(3 场景小样章)

## 实测结果(真实运行)

### 阶段 1:小说 → 结构化场景 ✅ 已跑通
输入样章 → `extract_script.py` 产出:

```
3 个场景,总时长 35 秒
scene-01 场景一:深夜办公室 (13s) 图像提示词:电影感镜头,办公室还亮着灯,竖屏9:16...
scene-02 场景二:车库交易     (11s)
scene-03 场景三:真相浮现     (11s)
```

每个场景自动生成:图像提示词 / 旁白台词 / 台词分段 / 时长分配

### 阶段 2:场景 → 配音 + 字幕 ✅ 已跑通
`generate_audio.py`(edge-tts 免费配音)产出:
- `voiceover.wav`(32 秒,1.5MB,多角色旁白)
- `字幕.srt`(精确时间轴)

```
1
00:00:00,000 --> 00:00:11,400
旁白:凌晨两点,办公室还亮着灯。 林晚(焦虑):这个方案再不过,公司就没了。...

2
00:00:11,400 --> 00:00:21,048
旁白:老板带林晚去了地下车库。 神秘人(低沉):东西带来了吗?...
```

### 阶段 3-4(需运行时):图像生成(ComfyUI/MUAPI)+ Remotion 合成
本机 ComfyUI 与图像 API 未在本 demo 中跑,买家环境配好即可全自动完成。

## 案例截图建议
- 截 scenes.json 的场景列表 + 字幕 SRT 时间轴
- 配文案:小说丢进去,场景/配音/字幕自动出来,剩下的图像和合成也全自动
